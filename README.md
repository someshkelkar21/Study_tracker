# Study Tracker

Study Tracker is a personal web application for planning, tracking, and measuring study progress.

It is also a learning project through which I am learning software development by building a real application step by step.

## Current Features

* Add subjects
* Add chapters to subjects
* Add topics to chapters
* Navigate through subjects, chapters, and topics
* Mark topics as completed
* Calculate chapter completion
* Calculate subject progress
* Display subject progress on the dashboard

## Tech Stack

* HTML
* CSS
* JavaScript
* Browser Local Storage
* Git
* GitHub
* GitHub Pages

## Current Status

The syllabus foundation of Version 0.1 is working.

The next planned step is adding Local Storage persistence so that the user's data can be saved between visits.

## Learning Project

This project is being developed incrementally to learn:

* JavaScript
* Application architecture
* State management
* Data persistence
* Git and GitHub
* Software design

The project is intentionally being built with vanilla HTML, CSS, and JavaScript before introducing any framework.

## Future Direction

The project may later expand into work planning, study time tracking, daily routines, timers, and time estimation.
